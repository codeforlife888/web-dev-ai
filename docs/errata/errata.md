## Gemini Code Assist

Google has officially retired and deprecated the consumer, individual, and free versions of Gemini Code Assist (including the free tier and consumer IDE extensions).

What was deprecated:
- **Gemini CLI & Consumer Extensions**: IDE extensions and the command-line interface for "Gemini Code Assist for individuals," Google AI Pro, and Google AI Ultra tiers stopped serving requests.
- **Gemini Code Assist for GitHub**: Consumer-level accounts on GitHub are also fully sunsetted.

What is still available:
- **Enterprise Users**: Gemini Code Assist Standard and Enterprise licenses remain fully supported, unchanged, and receive the latest model updates.
- **Alternative CLI Options**: The Antigravity CLI is the direct replacement. Alternatively, you can use the standard Gemini models via an AI Studio or Vertex AI API key.
